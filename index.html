PDF Editor éditeur de PDF

Outils

Sélection

Clique sur un élément pour le sélectionner. Glisse pour déplacer. Glisse dans le vide pour une sélection multiple. Suppr pour effacer.

Texte

Clique sur la page pour ajouter une zone de texte.

Dessin

Glisse sur la page pour dessiner.

Gomme

Clique sur un élément pour le supprimer.

Forme

Glisse sur la page pour créer une forme. Shift contraint, Alt dessine depuis le centre.

Fusionner des PDF

Ajoute plusieurs fichiers, ordonne-les, puis fusionne-les en un seul PDF.

    Aucun fichier ajouté pour l'instant.

    Compresser un PDF

    Réduit le poids d'un PDF en le convertissant en pages-images optimisées. Idéal pour les PDF scannés ou remplis d'images ; le texte ne sera plus sélectionnable dans le résultat.
